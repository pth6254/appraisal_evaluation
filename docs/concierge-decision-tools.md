# 대화 맥락과 자금·후보 비교 연결

## 사용 흐름

로그인 후 AI 컨시어지에서 케이스와 후보를 선택한다.

1. “이 후보 자금 분석해줘. 보유 현금은 3억이고 대출 비율은 50%야.”
2. 필요한 추가 조건을 안내받고 “금리 연 4%, 30년 원리금균등, 취득 후 1주택, 비조정지역, 기존 대출 없음, 연소득 1억, 월 상환 한도 200만원”처럼 보완한다.
3. “그럼 금리만 5%로 바꿔서 다시 계산해줘”로 이전 조건을 유지하며 재계산한다.
4. “후보 비교해줘”로 케이스의 저장된 후보를 비교한다. 비교는 후보를 개별 선택하지 않아도 실행된다.

금융 조건과 계산 결과는 채팅에 표시되며, 케이스 화면 링크로 상세 검토를 이어갈 수 있다. 최종 후보 선택이나 거래 결정은 자동 변경하지 않는다.

## 실행 경계

- Redis에 사용자·대화 ID별 검색 조건, 후보 선택, 금융 조건, 최근 4회 대화와 직전 도구 상태를 저장한다. 마지막 요청으로부터 24시간 유지한다.
- 후보·케이스 선택을 바꾸면 이전 금융 조건과 대화 이력을 추론 입력에서 제외한다. “새 대화 시작”으로 기억한 조건을 초기화할 수 있다.
- 같은 브라우저 탭에서 새로고침하면 사용자별 sessionStorage의 대화 ID로 서버 기록을 복원한다. 완료된 최근 20회 질문·답변과 결과, 마지막 요청의 케이스·후보 선택을 복원하며 금융 조건도 이어서 사용한다. 브라우저에는 본문 대신 ID만 저장한다.
- 대화가 만료되거나 선택한 후보가 삭제되면 복원을 중단하고 새 대화를 안내한다. 서버 연결 오류는 기록을 지우지 않고 재시도를 제공한다. 계정이 바뀌면 화면 상태를 재생성하며 다른 사용자의 대화 ID는 404로 처리한다.
- 아직 답변을 받지 못한 요청의 진행 상태, 마지막 메시지 이후 바꾼 미전송 선택, 입력 중인 초안의 복원은 지원하지 않는다. 탭을 닫은 뒤나 다른 기기에서의 대화 목록 복원은 별도 기능이다.
- 저장된 후보 ID도 매 요청마다 소유권과 존재 여부를 확인한다. 모델이 후보 ID를 바꾸어 실행할 수 없다.
- 금융 조건은 범위·자료형·유한 숫자 여부를 검증한다. 필수 조건이 부족하거나 잘못되면 계산하지 않는다. null은 기존 값을 삭제하지 않는다.
- 후보의 최신 희망가와 물건 종류를 서버에서 조회하고, `/simulation`과 공유하는 `execute_simulation`으로 계산·저장한다. LLM이 계산 결과를 재작성하지 않는다.
- 연소득·월 상환 한도가 없으면 DSR·상환 부담 검토가 남았음을 표시한다. 대출 승인 여부를 판단하지 않는다.
- 부가 투자 시나리오는 기존 계산기의 보유 3년·상승률 0%·임대수입 없음 조건을 사용하며 답변에 고지한다. 임대수입·보유기간 등 상세 시나리오 변경은 자금 분석 화면에서 진행한다.
- 비교는 `compare_case_candidates`를 재사용한다. 희망가·AVM 추정가·필요 현금·월 상환액 및 누락·갱신·위험 항목을 함께 안내하며 임의 순위를 만들지 않는다.

## 검증 (2026-09-12)

`tests/test_concierge_decision_tools.py`는 금융 입력 오류, 다중 턴 조건 유지, 실제 계산과 후보 저장, 금리 변경, 후보 교체·선택 해제, 삭제된 후보, 다른 사용자의 케이스·대화 접근을 검증한다. 모델 출력은 이 자동 테스트에서 고정한다.

`scripts/verify_concierge_decision_browser.cjs`는 실제 모델·계산기·Redis·PostgreSQL을 사용하는 Chrome 브라우저 검증이다. 임시 계정을 만들고 검증 후 삭제한다. 위 5개 메시지 흐름과 후보 교체를 통과했다. 희망가 6억원·현금 3억원·대출 50%·연 4%·30년 원리금균등 입력에서 필요 현금 309,600,000원, 부족액 9,600,000원, 월 상환액 1,432,246원이 표시되고 저장되는 것을 확인했다. 이는 계산 연결의 검증이며 금융기관 심사 또는 세무 정확성의 독립 검증은 아니다.

실제 모델이 `criteria`에 금융 필드와 선택 ID를 섞는 오류가 재현되어, 허용된 금융 필드만 이동 후 검증하고 선택 ID는 서버 선택과 일치하는 경우에만 제거하도록 보완했다. 상충하는 값은 계산하지 않는다.

실행 결과와 화면은 로컬 `evaluation-results/concierge-decision-live.json`, `concierge-decision.png`에 남는다. 이 브라우저 검증은 제한된 한국어 대화 사례이며, 모든 표현에 대한 의도·수치 추출 정확도를 보장하지 않는다. 다양한 표현의 정답셋 확대와 모델 추출 정확도 측정이 다음 개선 항목이다.
