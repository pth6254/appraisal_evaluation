# 서울 아파트 외 유형 확장

2026-09-12, 서울 25개 자치구의 2025년 10월~2026년 9월 매매 실거래를 기존 수집·적재 경로로 추가했다. 공식 원천 6개 × 25개 구 × 12개월, 총 1,800개 작업을 완료했고 실패는 없었다. 지역·유형·월별 IngestLog 완료 상태와 실제 저장 행 수를 대조했다.

| 유형 | 저장 거래(해제 포함) | 탐색 집계(해제 제외) | 거래 표시 지역 |
|---|---:|---:|---:|
| 연립·다세대 | 37,894 | 36,315 | 25 |
| 단독·다가구 | 3,977 | 3,718 | 25 |
| 오피스텔 | 12,215 | 11,663 | 25 |
| 상업·업무 | 12,000 | 11,257 | 25 |
| 공장·창고 | 1,284 | 1,219 | 22 |
| 토지 | 10,723 | 10,293 | 25 |

신규 거래는 78,093건이며 기존 아파트를 포함한 전체 저장 거래는 145,845건이다. 공장·창고도 25개 구의 300개 지역·월을 모두 조회 완료했으나, 유효 거래가 없는 지역은 탐색 집계에 나오지 않는다. 최신 월은 진행 중이고 향후 신고·정정·해제가 반영될 수 있다.

## 화면 반영

`/explore`에 단독·다가구, 공장·창고 선택 항목을 추가했다. 아파트 외 유형 선택 시 오른쪽 패널을 '지역 거래 현황'으로 표시하고 표본 수·최근 거래월·중앙값·평균을 안내한다. 관심 지역을 검토 케이스에 저장할 수 있다. 개별 물건은 케이스에서 직접 등록하며 자동 단지 후보 추천은 아파트에 한정된다.

## 검증

실제 Chrome에서 여섯 유형의 API 200 응답과 지역 거래 현황 표시를 확인하고, 토지 관심 지역을 새 케이스에 저장했다. 검증용 임시 계정은 삭제했다. 로컬 검증 자료는 `evaluation-results/other-properties-ui.json`, `other-properties-ui.png`와 `probe_other_properties.cjs`에 있다. 수집 실행기는 `evaluation-results/ingest_seoul_other_properties.py`다.

백엔드 전체 테스트와 고정 입력 평가, 프론트 타입 검사·린트·프로덕션 빌드를 통과했으며 프론트 Docker 이미지를 재빌드했다.

이번 확장은 서울 매매 실거래 기반 지역 탐색이다. 실시간 매물·호가, 전세·월세, 서울 외 지역 또는 아파트 외 개별 물건 자동 추천까지 제공하는 것은 아니다.
