# 법률·세금 챗봇 대화 기억과 복원

`/chat`의 로그인 사용자 대화를 Redis의 `law-chat:{user_id}:{conversation_id}`에 보관한다. AI 컨시어지 위젯과 별도의 기록이다. 최근 20회 완료된 질문·답변, 출처, 계산기 이름과 안내 문구를 복원하며 마지막 질문 후 24시간이 지나면 만료된다. 조회만으로 보관 기간이 연장되지는 않는다.

브라우저에는 사용자별 대화 ID만 sessionStorage로 저장한다. 같은 탭에서 새로고침하면 서버 기록을 불러온다. 계정이 바뀌면 화면 상태를 재생성한다. 만료된 기록은 새 대화로 안내하고 통신 장애는 기록을 유지한 채 재시도를 제공한다. '새 대화 시작'은 기존 대화 연결을 끊으며 서버의 이전 기록은 보관 기간 후 만료된다. 회원 탈퇴 시 해당 사용자의 법률·세금 대화 기록도 삭제한다.

최근 3회 대화가 답변 작성에 전달된다. 계산기 선택에는 이전 **사용자 발언**을 조건 보완용으로 전달하고 현재 질문의 변경 조건을 우선한다. '그 경우', '그럼' 등의 지시어로 시작하는 검색 질문에는 앞선 사용자 발언을 함께 사용한다. 과거 AI 답변을 검색어나 계산 조건으로 사용하지 않으며, 답변 생성은 새 검색·계산 결과와 기존 수치 검증을 따른다. 임의의 긴 대화나 모든 생략 표현을 완벽하게 해석한다는 의미는 아니다.

로그인 사용자의 후속 요청은 서버 기록을 사용하므로 클라이언트가 보낸 임의의 history로 저장된 조건을 덮어쓸 수 없다. 비로그인 API의 기존 일회성 답변 경로는 유지하며 비로그인 대화 복원은 제공하지 않는다.

아직 생성 중인 답변, 미전송 초안, 탭을 닫은 뒤나 다른 기기에서의 기록 복원은 지원하지 않는다. 자금·매물 비교 도구는 이 변경에 포함하지 않는다.

## 검증

- `tests/test_chat_conversations.py`: 맥락·출처 복원, 요청 history 위조 방지, 위젯과 기록 분리, 사용자 격리, 만료, 조회 시 TTL 유지, 검색·계산 라우팅 입력과 회원 탈퇴 정리.
- `scripts/verify_chat_restore_browser.cjs`: 실제 모델·법령 DB를 사용하는 Chrome 검증. 임차권등기명령 질문 → 새로고침 후 답변·원문 링크 복원 → '그 경우 어느 법원에 신청하나요?' 후속 질문을 확인했다. 새 대화에서 성인 자녀 5억 증여 질문 → 새로고침 → '배우자에게 같은 금액'으로 대상만 변경하여 계산기를 다시 실행하고, 새 대화 초기화 후 복원되지 않는 것도 확인했다.
- 결과와 화면: 로컬 `evaluation-results/chat-restore-live.json`, `evaluation-results/chat-restore.png`. 임시 검증 계정은 실행 후 삭제한다. 한정된 대화 흐름 검증이며 법률·세무 정확성 전체를 보증하는 평가가 아니다.
