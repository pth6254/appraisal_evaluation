# 챗봇 아파트 단지 추천 연결

2026-09-12: 기존에 비활성화되어 있던 `select_properties`를 실거래 단지 추천 서비스에 연결했다.

- 시·군·구 또는 법정동, 아파트, 매매 조건이 필요하다. 없는 조건은 보완 입력으로 안내하고 시·도만 지정하면 구나 동을 묻는다.
- 기존 대화의 지역·예산·최소 면적을 유지한다. 최소 면적은 거래 단위 하한으로 적용한다. 챗봇의 예산 상한은 시점수정 단지 평균 가격에 엄격하게 적용하며, 기존 탐색 화면의 10% 여유 예산과 구분한다.
- 최근 12개월 해제 제외 실거래를 기반으로 최대 5개 단지를 안내한다. 조회·집계 결과를 결정론적 문장으로 표시하므로 답변 작성용 LLM을 추가 호출하지 않는다.
- 실제 호가나 판매 중인 매물 조회가 아니다. 챗봇에서 바로 후보를 저장하는 기능은 추가하지 않았으며 동네 탐색에서 저장할 수 있다고 안내한다.

검증: 전체 백엔드 893개, 고정 입력 평가 33/33, 프론트엔드 타입 검사·린트·빌드 통과. `tests/test_concierge_complexes.py`는 예산 상한, 최소 면적, 후속 조건 유지, 미지원·불완전 입력, 답변 모델 재호출 방지를 검증한다.

실제 브라우저에서 ‘역삼동 8억 이하 아파트 매매 동네’ 후 ‘그럼 구체적으로 아파트 단지 추천해줘’를 질문해 역삼동 단지 5개와 예산 유지·화면 표시를 확인했다. 해당 실행의 동네 답변은 약 9초, 후속 단지 추천은 약 7초였다. 단일 실행 측정으로 일반적인 응답 시간 보장은 아니다. 로컬 검증 이미지: `evaluation-results/chat-complexes.png`.
